# Lite Me（人类省电模式）

给每天工作很久、下班后只剩零碎时间和精力的人的自我照顾 Agent。它不给固定的健身或饮食计划，而是在你下班那一刻，把「今天照顾自己」缩成不能再小的三件事：**吃什么、动多久、几点停**。目标不是单日最优，是让你**长期不归零**。

打开就是结论不是问卷：先给一版今晚的建议，猜错了一键改回来，一天只打扰你一次。

## 跑起来

```bash
pip install -r requirements.txt
uvicorn backend.main:app --host 0.0.0.0 --port $PORT
```

环境变量（兼容 OpenAI 协议的模型服务即可，默认按阿里云百炼配）：

| 变量 | 说明 | 默认 |
|---|---|---|
| `LLM_API_KEY` | 模型 key（必填） | — |
| `LLM_BASE_URL` | 如 `https://dashscope.aliyuncs.com/compatible-mode/v1` | — |
| `CHAT_MODEL` | 文本+工具调用 | `qwen-plus` |
| `VISION_MODEL` | 食物拍照识别 | `qwen-vl-max` |
| `EMBED_MODEL` | RAG 向量检索 | `text-embedding-v4` |

首次启动自动建库（SQLite `app.db`，含迁移）。前端是纯静态页，托管在 `/`，打开即用。
RAG 语料向量 `data/corpus.npz` 已在仓内；可选执行 `python scripts/build_corpus.py` 重建检索表（不执行也能出建议，只是少了指南引用）。

## 架构

```
frontend/  4 张静态 HTML（零框架，直调后端）
    │
backend/main.py    路由 + 即时安全闸门 + per-user 锁（防并发双重生成）
    ├─ agent.py    Agent 主循环：工具调用 ≤6 轮 + RAG 检索 + 档位系统
    ├─ safety.py   三层安全边界（词表 → LLM 分类 → 代码 enforce，只能加严）
    ├─ extract.py  自由输入 → 时间/精力/身体 三项结构化抽取（词表优先，LLM 兜底）
    ├─ rag.py      指南语料向量检索（膳食/运动/睡眠权威手册）
    ├─ mcp_server.py  自建 MCP（Streamable HTTP，零依赖实现）
    ├─ db.py       SQLite（WAL），clock.py 全局虚拟时钟（演示道具）
    └─ llm.py      OpenAI 兼容协议封装
```

几个刻意的工程决策：

- **安全边界"检测可用 AI，执行必须代码兜底，只能加严"**：LLM 分类失败会退回确定性词表；`enforce` 在代码层无条件撤掉危险状态下的运动建议——模型说什么都越不过它。
- **带模型调用的路由全部普通 `def` 进线程池**：一次生成 10–20 秒，不能冻住事件循环；配 per-user 锁 + SQLite WAL 保证并发下不双重生成、不锁库。
- **演示不死**：任何失败路径（模型超时、识别失败、检索为空）都有兜底输出，不白屏不报错。
- **虚拟时钟**：底部时钟条把「过一天」压缩成可当场演示的动作（回执 → 次日档位变化本来要等 24 小时）。

## 三层安全边界

1. **档案级**：填写确诊严重疾病 → 温和劝退，绝不给专业医疗建议；慢性病 → 建议整体降调、档位封顶。
2. **词表级（确定性）**：胸闷、心悸、头晕等急性信号命中即 danger，立刻停掉所有活动、只建议就医。
3. **模型级（只加严）**：LLM 分类器补词表覆盖不到的说法（"以前疼现在不疼了"不该误报），结果只能让等级更严不能放松。

安全测试：`scripts/test_safety.py`（113 个用例）+ `scripts/safety_regression.py`（端到端回归，对运行中的服务打真实请求）。

## 自建 MCP

`/mcp`（Streamable HTTP，无需鉴权头）。5 个工具对应产品核心循环：

| 工具 | 作用 |
|---|---|
| `about_lite_me` | 产品说明与体验顺序 |
| `start_night` | 「下班了」：真实 Agent 链路生成今晚建议 |
| `get_tonight_state` | 今晚判断三行 / 建议 / 回执状态 |
| `add_note` | 补充一句（说「有点胸闷」可看安全边界当场接管） |
| `submit_feedback` | 回执，驱动次日档位调整 |

工具作用于评测专用账号（自动创建），带模型的工具有每日调用上限。
