## 一、落地清单（对照计划 P4 九项）

1. **多屏骨架**：show() + 按屏配置返回箭头（只 confirm/settings 有）+ 齿轮只挂 Home；s-accepted/s-bye 无返回（NOBACK 语义：到达即落定）。
2. **Home**：问候 tag（按虚拟时间分五档）+ 回顾卡位 + 树洞/食记两格（气泡面板）+「开始今晚」+ 安全出口 + 下班提醒条（②-19 逻辑照搬旧版：localStorage + 30s 轮询虚拟时钟，视觉换成卡片）。
3. **回执流**（②-20/21）：不在 Home 常驻（③-8）；offwork 返回 need_feedback 或「点错了？改」时出现；显示队友文案（做到了/做了点/没顾上）+ 值用后端四档 + 「建议仍然太难」minor 行 + 「跳过」textlink；「昨晚记为 X · 点错了？改」行常驻。
4. **s-confirm**（③-7）：三行判断全部来自 B1 `confirm_hint`（时间/精力带「估」标、身体=暂未确认、basis 原文）；「改一下」→ adjust-sheet（紧凑时间滚轮 20–180×10 默认停在 remaining_min、精力三档预置 guess、身体两档默认不选=暂未确认）→「按这个重新算」→ `offwork {calibration}`；「判断大致没错」→ `offwork {}`。**回执待收时校准值前端暂存，答完自动续跑**（B2 牵连 5）。
5. **结论屏**：judgement→H1、reason+sources→理由行（source-row 默认收起）、eat/move/stop→plan 清单（null 缺席、CSS counter 编号、停带「核心」）、时间带（now=虚拟时钟、睡点=confirm_hint、通勤段=eta−now 斜纹；解析不出整条隐藏；"今晚需要你花的时间"已删 ③-13）；「就这样」→ 印章屏（①-8，不写本地历史，印 stop 或 judgement）。**安全五件套容器已带**（avoid/see_doctor/severe_notice/disclaimer 基础位，空即隐藏——P5 收口视觉与 sober）。
6. **补充抽屉**：补充一句→`/api/free_input`；快捷区四钮（换一种做法/再轻一点/再加一点/其实我做了，类型字符串与后端逐字对齐）；再加一点在 safety_level≠none 隐藏、换一种做法在 crisis 隐藏（B3 口径）；到顶/到底只 toast 不重渲染（②-17/18）；「今天不做」→ s-bye 纯前端（③-16）。
7. **树洞/食记**：树洞→`/api/free_input`（加了「说给它」提交链接与 Enter 提交——原型是本地解析无提交件，真实接口需要显式发送）；食记单张上传→`/api/meal/photo`+确认句+「记错了？删除」（③-15）。
8. **trace**（②-24）：理由行下折叠组渲染 `/api/agent_trace` steps，安全层行天然带出（实测出现"安全层：分类器判定 none…"）。
9. **时钟条 + 30s 轮询 + toast**：逻辑照搬旧版换皮；轮询不打断 confirm/抽屉；换天后清 currentAdvice 交给 refreshState 重判。

## 五、问题与潜在问题

1. **安全出口按钮不受 loading 禁用**（只禁 .btn.primary）：生成中点「身体不舒服」会再发一次请求。后端有 _user_lock + 当天已生成检查兜底，不会重复生成，但会多一次无效往返。P5 收口安全出口时一并把 .safety 纳入禁用。
2. **s-confirm 的 H1 是前端映射**（很低→"今晚先按省力的来"，否则"先对一下今晚的判断"）：非模型生成、不虚构数据，但文案是我定的，你过目不满意随时改。
3. **树洞的「说给它」提交件是新增设计**：原型树洞无提交按钮（本地即时解析），真实接口必须显式发送。用了 textlink 形态融入气泡，若你想要 mic 位置的图标按钮再调。
4. **30s 轮询只刷新时钟与提醒条**，不切视图（沿用旧版设计，避免打断操作）；拨时钟按钮才触发全量 refreshState。
5. **临时设置屏**：齿轮进的是极简版（基本情况/常吃的/退出登录三行 + 说明），P6 按计划重做完整外壳。
6. **印章屏「好，先这样」回结论屏**而非原型的 s-stop 停下提示屏——停下提示依赖推送时机，网页版无对应机制（③-11 同理），本期不做，记后续需求。
7. **band 通勤段用 eta−now 计算**：未到下班点时会把"等下班+通勤"都画进斜纹段（语义是"到家前的时间"），标签写"路上 X 分"在下午看会偏大；晚间演示时段无此问题。
