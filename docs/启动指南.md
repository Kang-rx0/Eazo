# 启动指南

> 更新日期：2026-08-07（以真实日期为准，与演示用的虚拟时钟无关）

## 一、环境要求

| 项 | 值 |
|---|---|
| Python 环境 | conda 环境 `Eazo`（`/opt/miniconda3/envs/Eazo`，Python 3.11） |
| 运行时依赖 | `fastapi uvicorn openai numpy python-dotenv python-multipart` |
| 爬虫脚本额外依赖 | `requests beautifulsoup4 pdfplumber`（只有 `scripts/crawl_corpus.py` 用） |
| 配置文件 | 项目根目录 `.env`（见下） |

依赖已全部装在 Eazo 环境里。如换机器重装：

```bash
/opt/miniconda3/envs/Eazo/bin/pip install -r requirements.txt python-multipart requests beautifulsoup4 pdfplumber
```

## 二、.env 配置

项目根目录 `.env`，**只认这一套变量名**（不做兼容回落）：

```
LLM_BASE_URL=（百炼 OpenAI 兼容接入点，形如 https://xxx.aliyuncs.com/compatible-mode/v1）
LLM_API_KEY=sk-xxx
```

模型名不在 `.env` 里，写在 `backend/config.py` 的默认值：
`qwen-plus`（文本）/ `qwen-vl-max`（视觉）/ `text-embedding-v4`（向量）。要换模型改 `config.py`。

## 三、启动 / 停止

```bash
cd /Users/kang/Desktop/Eazo/MVP2
/opt/miniconda3/envs/Eazo/bin/uvicorn backend.main:app --port 8100
```

- 开发时可加 `--reload`（改后端代码自动重启）。
- 首次启动会自动建库建表（`app.db`）并播种虚拟时钟，无需手工初始化。
- 浏览器访问：**http://localhost:8100** （介绍页 → 登录/注册 → 主界面）。
- 停止：前台运行按 `Ctrl+C`；后台运行用 `pkill -f 'uvicorn backend.main:app'`。

### 验证是否起来了

```bash
curl -s http://127.0.0.1:8100/index.html -o /dev/null -w '%{http_code}\n'   # 期望 200
```

## 四、端口占用一览（本机现状）

| 端口 | 占用者 | 说明 |
|---|---|---|
| **8100** | 本项目后端（`uvicorn backend.main:app`） | 前端静态页 + 全部 `/api/*` 都在这个端口 |
| 8000 | 另一个项目的服务（`uvicorn api.main:app`，同样跑在 Eazo 环境） | **不是本项目**。本项目最初想用 8000，发现被它占了才改用 8100 |

要换端口：启动命令里改 `--port`，前端不用改（页面用相对路径调 API，同源生效）。

## 七、常见问题

- **启动报 `address already in use`**：端口被占，`lsof -nP -iTCP:8100 -sTCP:LISTEN` 看是谁，换端口或杀掉旧进程。
- **建议生成很慢/失败**：查 `.env` 的 key 是否有效；模型全挂时系统会返回写死的兜底建议（"饭后走8分钟 / 23:00放下手机"），不会白屏。
- **想从零开始**：停服务后删 `app.db` 再启动（会重建空库；`corpus_chunks` 也会被清掉，需重跑 `build_corpus.py`）。
